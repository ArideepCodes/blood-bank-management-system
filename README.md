## ✨ Overview

The **Blood Bank Management System** is a modern web-based application developed to simplify and automate the blood donation and blood request process.

The platform connects donors, patients, hospitals, and administrators through a centralized system that improves communication, reduces manual work, and enables faster emergency response.

This project was developed as a Final Year B.Tech Project for the Department of Computer Science & Engineering.
