# ✨ Overview

The **Blood Bank Management System** is a modern healthcare-focused web application developed to simplify and automate the blood donation and emergency blood request process.

The platform connects:
- donors
- patients
- hospitals
- administrators

through a centralized system that improves communication, reduces manual effort, and enables faster emergency response during critical situations.

This project was developed as a **Final Year B.Tech Project** for the Department of Computer Science & Engineering.
